# Screenly — Design

Calm editorial responsive web landing page. Ivory #f8f7f2 canvas, forest #183e32 ink, lime #d9ef8a accents, muted #74796e. Poppins display/body paired with expressive italic Georgia. Oversized 84px desktop headlines, 48px mobile; content width 1200px; 64px desktop and 24px mobile gutters. Fine dividers, pill actions, generous space. CSS-drawn orbit motif and three interactive app previews rather than photography.

Homepage: split hero, product demos, editorial problem statement, dark commitment section, science link, FAQ, final CTA and footer. Editable demo limits, daily chart selector, invite dialog, native FAQ. Download dialog clearly states store links are pending and only saves device preference locally. No real signup claims. No API or database changes. Scientific framing links to a commitment-device review without claiming product-specific efficacy. Accessible focus states, dialog keyboard support and reduced motion.
